# MoonNote · 便利贴 + 待办清单

> 一个长在桌面上的小本子。左边贴便签，右边排任务，两样东西共用一个文件。

**Windows · 免费 · 无广告 · 不联网 · 数据全在本地**

---

## 它解决什么问题

大多数待办工具要么太重（登录、同步、订阅），要么太轻（一个文本框）。

MoonNote 想当中间那个：**打开就在、随手能记、关掉不丢**。

- 脑子里突然冒出来的事 → 双击桌面开一张便签
- 正经要做的事 → 进右边的清单，给它一个优先级和截止时间
- 干完了 → 打个勾，它自己沉到列表底部

不用注册，不用联网，没有会员。

---

## 桌面便签

- 想开几张开几张，各自拖动、缩放、置顶
- 六种纸色可选，或者自己调 RGB
- 边打字边自动保存，没有「保存」按钮
- 关掉便签不会丢内容，下次还在原来的位置

## 待办清单

| 列 | 说明 |
| --- | --- |
| 状态 | 点一下打勾 / 取消，只有这个按钮响应鼠标 |
| 任务 | 说清楚要干什么 |
| 优先级 | 五档，见下 |
| 截止日期 | 精确到分钟 |
| 剩余 | 自动算，逾期会变红 |

- **智能排序**：没做完的在上、重要的在上、快截止的在上，做完的沉底
- **筛选**：全部 / 未完成 / 已完成
- **批量**：一键完成、一键复位、一键删除（都有二次确认，不会手滑）

## 轻重缓急，分五档

不是重要/紧急四象限，是更口语的五档：

> 🔴 天塌了 · 🟠 十万火急 · 🟡 岁月静好 · 🟢 佛系躺平 · ⚫ 来世再见

点开是个圆点列表，每个圆点对应一档颜色，选完直接生效。

## 纸感界面

- **明暗双主题**：纸白 / 夜墨，一键切换，标题栏图标跟着反色
- 无系统边框，自己画的圆角 + 阴影
- 字体大小可调：齿轮 → 字体大小，**拖动滑块实时预览**，右边到顶也不会撑破布局
- 全部控件统一视觉语言，没有突兀的 Windows 原生弹窗

## 数据是你自己的

- 存成**一个 JSON 文件**，放在 `%APPDATA%\MoonNote\data.json`
- 想搬走就搬：设置里可以改存储目录，会帮你整体迁移
- 备份三件套：
  - 一键复制全部数据到剪贴板（发给自己就行）
  - 导出成 .json 文件
  - 从剪贴板 / 文件恢复
- **导入前自动留一份 `data.before-import.json`**，覆盖错了还能找回来

## 一些小地方

- **常驻托盘**：关掉窗口不退出，托盘图标点一下叫回来
- **开机自启**：设置里一个椭圆拨动开关，开了就在托盘等你
- **空状态会换图**：全部干完的时候，会有一只鼠鼠给你鼓掌
- **可以换成你自己的图**：往 `assets/finish-img/` 里丢任意图片，支持 GIF，自动裁白边
- **换头像**：关于页的长按可以换，同样支持任意格式

## 数据在哪

```
C:\Users\<你的用户名>\AppData\Roaming\MoonNote\data.json
```

卸载软件**不会**删这个文件。想彻底清干净，手动删掉整个 `MoonNote` 文件夹。

## 常见问题

**装的时候弹了 SmartScreen 警告？**
没有买代码签名证书（一年好几千）。点「更多信息 → 仍要运行」即可。

**能不能同步到手机？**
不能，也没打算做。数据就是一个 JSON，想同步的话丢进你的网盘目录就行。

**会不会偷偷联网？**
不会。这个程序唯一的网络行为是检查更新（如果开启），其余全在本地。
